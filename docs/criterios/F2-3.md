```gherkin
Funcionalidade: Formulário de criação de questão

Regra de negócio: O formulário deve exibir apenas os campos necessários para o tipo de questão selecionado.

  Cenário: administrador acessa formulário de criação de questão
    Dado que um administrador está autenticado
    Quando acessa a página de criação de questão
    Então o formulário exibe os campos de tipo, enunciado e solução

  Cenário: administrador cria questão dissertativa
    Dado que o tipo selecionado é dissertativa
    Quando o formulário é exibido
    Então os campos de alternativas e gabarito não são necessários

  Cenário: administrador cria questão de múltipla escolha
    Dado que o tipo selecionado é múltipla escolha
    Quando o formulário é exibido
    Então os campos de alternativas e gabarito são exibidos
```
