```gherkin
Funcionalidade: Editar questão

Regra de negócio: Qualquer administrador pode editar qualquer questão.

  Cenário: administrador edita questão de outro administrador
    Dado uma questão criada por um administrador
    Quando outro administrador altera seus dados
    Então as alterações são salvas
    
  Cenário: Alterar uma questão dissertativa para múltipla escolha
    Dado que existe uma questão dissertativa cadastrada
    Quando um administrador edita a questão alterando seu tipo para múltipla escolha
    E informa alternativas e gabarito
    Então a questão deve ser salva como múltipla escolha
    E deve possuir as alternativas e o gabarito informados

  Cenário: Alterar uma questão múltipla escolha para dissertativa
    Dado que existe uma questão de múltipla escolha cadastrada
    Quando um administrador edita a questão alterando seu tipo para dissertativa
    E informa uma nova solução
    Então a questão deve ser salva como dissertativa
    E não deve possuir alternativas ou gabarito
```
