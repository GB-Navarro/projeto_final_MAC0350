```gherkin
Funcionalidade: Criar questão

Regra de negócio: Um administrador autenticado pode criar uma questão.

  Cenário: administrador cria uma questão dissertativa
    Dado um administrador autenticado
    Quando ele cria uma questão dissertativa
    Então uma questão é criada associada a esse administrador

  Cenário: administrador cria uma questão de múltipla escolha
    Dado um administrador autenticado
    Quando ele cria uma questão de múltipla escolha com alternativas e gabarito
    Então uma questão é criada com esses dados associada a esse administrador
```
